# Three-minute demo script

1. Introduce the problem: anime discovery can be overwhelming.
2. Open the Streamlit interface and select a familiar anime.
3. Describe a desired mood or genre and limit episode count.
4. Explain why the results are ranked: text features, TF-IDF, cosine similarity.
5. Show that a selected favorite is excluded and the episode filter is enforced.
6. Explain limitations: small offline catalog, no live ratings or LLM.
7. Describe next steps: bigger datasets, ranking metrics, review sentiment evaluation, and agent tools.
