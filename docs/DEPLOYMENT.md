# Deployment guide

## Local
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud
1. Push this repository to GitHub.
2. Open Streamlit Community Cloud and select **Create app**.
3. Choose the repository and `main` branch.
4. Set entrypoint to `app.py`.
5. Deploy and verify the URL.

A public deployment is not included or verified by this repository alone.
