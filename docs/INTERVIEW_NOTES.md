# Portfolio discussion notes

## What did you build?
A small interactive content-based anime recommendation prototype with a reusable sentiment-classification module.

## Why TF-IDF?
It is transparent, lightweight, and easy to debug for a text-based baseline.

## Biggest technical risks
Small catalog bias, poor synonym handling, lack of relevance labels, and train/test leakage in future sentiment data.

## What would you improve?
Use a larger licensed dataset, evaluate ranking on real interactions, validate sentiment on held-out reviews, and add cited tool-using LLM features.

## What did this exercise demonstrate?
Data validation, feature engineering, text similarity, supervised classification, testing, and UI integration.
