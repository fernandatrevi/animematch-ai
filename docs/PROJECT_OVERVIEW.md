# Project overview

AnimeMatch AI explores how machine learning can improve anime discovery. The current goal is a reproducible content-based recommender that works without external accounts or paid services.

## User problem
Anime fans may know which shows they enjoy but struggle to discover similar shows under a time constraint.

## MVP
The user selects favorite shows, enters a short description, and optionally limits episode count. The application returns ranked unseen shows with explanations.

## Success criteria
The app starts locally, accepts valid preferences, filters episode counts correctly, and never presents similarity as a calibrated enjoyment probability.
