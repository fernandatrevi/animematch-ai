# Data dictionary

| Field | Type | Meaning |
|---|---|---|
| title | string | Display name of anime |
| genres | string | Space-separated genre/theme descriptors |
| synopsis | string | Short plot description |
| score | float | Illustrative demo score, not live rating |
| episodes | number | Number of episodes used for filtering |

The demo catalog is hand-curated. Do not use it to report statistical accuracy or population-wide patterns.
